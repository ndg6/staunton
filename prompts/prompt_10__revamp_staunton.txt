We've come a long way with Typst plugin "Staunton" and it's only now, that I can
fully formulate my vision for this plugin. This is also to differentiate "Staunton"
from other Typst chess plugins like "boards-n-pieces" (on Typst Universe)
to see what we can and should do and where we can improves.

Staunton is a Typst (https://typst.app) plugin to make chess publishing
easy and adaptable. Chess publishing has several aspects.

- visual representation of chess games, most prominently of course
	chess positions on a chess board, possibly turning those boards
	into fully fledged diagrams with captions, labels etc., so they
	can be treated as Typst #figures.
	
- printing chess moves (as text) in various forms, including potentially in
    different languages and with annotations, comments and diagram printing instructions.

- creating tables for multi-game PGNs:
    - cross tables
    - progress tables

- capturing structure with chess-specific outline instructions:
    - for diagrams
    - for tables
    - possibly support internationalization

We specifically want to support both fully automated printing of chess
diagrams and move text with instructions solely stemming from existing game scores
(in PGN form) as well as a programmatic and free form approach for
printing, highlighting and arrows when a game score was already read in.
We don't want to alter existing PGN for that but use functions instead.
